# Theme Switcher 🌗

A simple and responsive **Theme Switcher** built with React.js. This project demonstrates how to use **React Context API and Hooks** to manage and switch the application's theme globally.

## 🚀 Features

* 🌞 Light Mode
* 🌙 Dark Mode
* ⚛️ React Context API
* 🔄 Global theme state management
* 🎨 Dynamic styling
* 📱 Responsive UI

## 🛠️ Technologies Used

* React.js
* JavaScript
* Context API
* React Hooks
* Vite
* CSS

## 🧠 Concepts Learned

This project helped me understand:

* `createContext()`
* `useContext()`
* `useState()`
* Context Provider
* Global state management
* Passing data and functions through Context
* Conditional styling based on application state

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/SuryanshSharma31/ThemeSwitcher.git
```

Go to the project directory:

```bash
cd ThemeSwitcher
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 🎯 Purpose

The main purpose of this project is to practice **React Context API and global state management** by creating a practical Light/Dark theme switching application.
